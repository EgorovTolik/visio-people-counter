# AGENTS.md — visio-people-counter

## Сначала прочитай навык проекта
Перед ЛЮБОЙ работой в этом проекте загрузи и следуй локальному навыку:
`.pi/skills/vpc-project-workflow/SKILL.md` (или `/skill:vpc-project-workflow`).

Там зафиксированы обязательные правила владельца:
- работа строго через субагентов, **последовательно по одному** (никакой параллели);
  спецификации задач — `pi-research/tasks/NN-*.md`, результаты — отдельные файлы `pi-research/*.md`,
  ответ субагента — только резюме + путь к файлу;
- окружение: только `.venv/bin/python` (PEP 668 — ничего в системный python),
  тесты: `.venv/bin/python -m unittest discover -s tests -t .`;
- методика исследований (DuckDuckGo через curl, rate limits GitHub API,
  референсы только в `references/repos/`);
- **git: коммиты и push — ТОЛЬКО после явного подтверждения владельца**;
- карта проекта и быстрые команды CLI.

## Кратко о проекте
Консольный подсчёт человеческого трафика на видео (HLS URL или файл): Python + OpenCV,
детекция движения (MOG2/KNN) → фильтры → трекер SORT/ByteTrack (вспомогательно) →
счётчики (наклонная линия / зона, in/out, антидвойной-счёт). Исходники — `visio_people_counter/`,
исследования и отчёты — `pi-research/`, шаблон конфига — `config.example.yaml`.
