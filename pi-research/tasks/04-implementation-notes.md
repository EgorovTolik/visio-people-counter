## Твоя задача
Составь детальные implementation notes — техническую основу для проектирования, опираясь
на отчёты и код референсов. Разделы:

### 1. Целевая архитектура: модули и dataflow
Предложи структуру нашего проекта (имена модулей/классов + их ответственность):
VideoSource (HLS-через-ffmpeg-pipe / файл), MotionDetector (MOG2+морфология+компоненты),
TrackerAdapter (roboflow/trackers: как превратить bbox'ы blob'ов в sv.Detections и обратно,
какие track_cfg/параметры для CPU — проверь в коде references/repos/trackers, какие именно
параметры есть в ByteTrack/SORT config, типичные значения), LineCounter (пересечение линии,
направление, антидубль), Config/калибровка (линии, ROI, пороги — какой формат конфигурации:
YAML с координатами нормализованными 0..1?), CLI-обвязка. ASCII-схема dataflow.

### 2. Детали LineCounter
Псевдокод на Python для нашего случая: НАКЛОННАЯ линия (2 точки), оба направления,
пересечение по отрезку prev→cur (чтобы не терять при пропусках кадров), антидубль-набор:
track_id флаг + cooldown по wall-clock + зона "буфера" вокруг линии. Показатели, которые
логировать при каждом событии (track_id, координаты, направление, время кадра).

### 3. Адаптация к разным размерам объектов
Конкретный механизм: как задать порог площади по сегментам линии в конфигурации;
формула/подход интерполяции; какие ещё параметры масштабировать (cooldown, мин. дистанция
между событиями, морфологические ядра?). Как оператору это настраивать (калIB-режим:
показать кадр + нарисовать линию мышью — опиши UX, достаточно cv2.setMouseCallback).

### 4. Ввод HLS/файл
Точная команда ffmpeg для pipe (fps, размер, retry), как получать w/h/fps через ffprobe,
watchdog переподключения (псевдокод: N неудачных read → restart), поведение на EOF для файла.
Отдельно: что делать с задержкой стрима (нужна ли "live" или ок 10–30 сек?).

### 5. Производительность на CPU
Оценка по кадрам: MOG2.apply + морфология + connectedComponents на 1920×1080 (типичные ms),
трекер ByteTrack/SORT на N объектов; вывод: какой fps реально достижим, имеет ли смысл
даунскейл к 1280×720 / обработка при 10–15 fps. Проверь в коде trackers, что тяжёлого там нет (torch?).

### 7. Риски и открытые вопросы для владельца проекта
