# Задача 01: Веб-исследование методов подсчёта людей на видео (OpenCV + Python)

## Контекст проекта
Мы разрабатываем инструмент подсчёта человеческого трафика. На вход — видеопоток
(веб-ссылка на HLS или путь к файлу). Сервис ищет движущиеся объекты, ведёт подсчёт,
а механизм трекинга используется вспомогательно, чтобы не считать один объект дважды.
Камера: уличная камера видеонаблюдения с широкой перспективой — размеры объектов в кадре
сильно различаются (даль/близ). Основной стек: Python + OpenCV.

## Твоя задача
Проведи веб-исследование (web_search / fetch_content) и составь обзор, КАК подобные задачи
решают с помощью OpenCV/Python. Это первая задача в серии — ничего не дублируй (дублей нет).

Что изучить:
1. Стандартный конвейер "background subtraction → контуры → фильтрация → счётчик":
   - cv2.createBackgroundSubtractorMOG2 и cv2.createBackgroundSubtractorKNN: параметры,
     плюсы/минусы, когда какой выбирать;
   - постобработка маски: морфология (open/close), connectedComponentsWithStats,
     фильтрация по площади/perimeter-соотношению/aspect ratio.
2. Стратегии подсчёта: линия пересечения (counting line) vs зона (ROI zone):
   - как детектить пересечение линии центром bbox с учётом направления;
   - как избежать двойного срабатывания (hysteresis, "уже прошёл" флаг, таймаут/мин. дистанция);
   - подсчёт по направлению (в обе стороны) vs общий трафик.
3. Трекинг как вспомогательный механизм:
   - встроенные трекеры OpenCV (KCF, CSRT, MOSSE): возможности, ограничения;
   - SORT/DeepSORT и подобные (byte-track): зачем они, что дают для де-дупликации счёта,
     насколько сложны в внедрении.
4. Детекция людей (опционально вместо "любого движения"): Haar-каскады, HOG+DNN,
   YOLO — кратко: стоит ли вообще детектить именно людей или достаточно движения.
5. Учёт разных размеров объектов (широкий угол): адаптивные пороги площади,
   масштабные пирамиды, нормализация по отрезку линии и т.п.
6. Чтение HLS-стрима в Python: cv2.VideoCapture с URL, роль ffmpeg, типичные проблемы
   (буферизация, задержка, потеря кадров), альтернативы (ffmpeg → pipe).
